# Keluaran lokal

Keluaran di folder ini diabaikan Git; README ini tetap dibagikan. Simulasi dapat menghasilkan `outputs/simulation.json`, berlabel sintetis dan bukan hasil inferensi.

Pipeline video nantinya memakai `outputs/<run_id>/` untuk events.csv, counts.csv, run.json, dan annotated.mp4 sesuai CONTEXT. File dari run gagal atau simulasi tidak dinyatakan sebagai hasil video lengkap.
