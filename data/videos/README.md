# Video sumber lokal

Letakkan rekaman MP4 jalan dari kamera diam di folder ini. Video diabaikan Git; README ini tetap dibagikan. Mulai dengan klip siang 30–60 detik dan kendaraan yang terlihat jelas.

Catat sumber/izin, resolusi, FPS, durasi, kondisi pengamatan, serta pemisahan data pengembangan dan uji di metadata anotasi. Video jalan nyata belum tersedia. Klip `synthetic_bus_translation.mp4` yang dibuat lokal hanya menggeser foto contoh secara buatan untuk menguji integrasi model; ia bukan rekaman lalu lintas atau dataset training.

Baca [panduan data](../../docs/video-data-guide.md). Baseline memerlukan MP4 CFR dengan dimensi genap untuk ekspor H.264; CLI `inspect` memeriksa metadata dan frame awal.
